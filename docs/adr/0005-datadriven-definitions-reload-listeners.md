# ADR-0005: Определения видов и сортов — reload listeners с мягкой валидацией

## Статус
Предложено (2026-10-29)
Ревизия 2 (2026-10-31, spike S12, `docs/spikes/S12-trade-events.md`): первая загрузка определений идёт до `ServerAboutToStartEvent` (торговые события Forge видят снимок); `apply` выполняется на `main` при старте и на `Server thread` при `/reload`, поэтому ссылка на снимок `volatile`. Принято.

## Контекст
Виды (`data/<ns>/crop_species`), сорта (`data/<ns>/cultivars`), роли качества и шаблоны деревень задаются JSON (видение п. «Данные, а не код»). Ошибка в JSON не должна ронять сервер: запись пропускается с понятным сообщением. Клиенту нужны имена, архетипы и `food_reference`, но не генетические параметры.

## Решение
- Загрузка через `AddReloadListenerEvent` (`SimplePreparableReloadListener`): виды → сорта → роли → шаблоны.
- Разбор через Codec (DFU), затем `DefinitionValidator` движка. Ошибка → `Problem(file, jsonPath, message)`; `ERROR` пропускает запись и зависимые от неё, `WARN` подставляет значение по умолчанию. Исключения ловятся на уровне записи.
- Результат — неизменяемый `DefinitionsSnapshot`, который атомарно подменяется (`volatile`-ссылка или `AtomicReference`: `apply` идёт на разных потоках при старте и при `/reload`, S12). Изменения применяются к растениям и предметам лениво при следующем обращении.
- Итоговая строка в лог, сообщение операторам при ошибках.
- Синхронизация: свой пакет `DefinitionsSync` в `OnDatapackSyncEvent` — только поля для UI и рендера (≈ 5–15 КБ). Крупный пакет режется на части сам: Forge не разбивает `SimpleChannel` (ADR-0013, S14).

## Альтернативы
1. **Datapack registries Forge** (`DataPackRegistryEvent.NewRegistry`). Автосинхронизация и Holder-ссылки, но ошибка в записи не даёт открыть мир, а `/reload` их не перечитывает. Противоречит требованию «без краша». Отклонено.
2. **Конфиг-файлы вне датапака.** Не сочетается с датапаками модпаков и с волнами.

## Последствия
- Плюсы: устойчивость к плохим датапакам, `/reload` для авторов, контроль над тем, что уходит клиенту.
- Минусы: своя синхронизация и свой порядок загрузки; ссылки на виды — по `ResourceLocation`, а не через Holder, поэтому висячие ссылки проверяет валидатор.
