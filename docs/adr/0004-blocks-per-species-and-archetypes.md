# ADR-0004: Свой блок на встроенный вид + архетипные блоки; рендер по BlockState

## Статус
Предложено (2026-10-29)

## Контекст
Блоки регистрируются при запуске, до загрузки датапаков. При этом метрика 6 требует, чтобы вид, добавленный только JSON, рос и давал сорт. Нарратив предлагает «один блок на вид» (`04-narrative.md` §7.9). Рендер должен показывать стадию, размер (`0.4 + 0.8·P`), чахлость и окраску без пересчёта фенотипа (GDD §13) и без отправки генома клиенту.

## Решение
- **Встроенные виды** получают свой блок (`wild_carrot`, …, `apple_trunk`, `gourd_fruit`, `watermelon_fruit`), созданный из общего класса архетипа с параметром «вид». Ванильные модели blockstate, имена, ресурспаки.
- **Датапачные виды** используют архетипные блоки `generic_*` (field, tall, water, vine + vine_fruit, bush). Модель общая, цвет — из JSON вида через `BlockColor` (клиенту из BE синхронизируется только id вида). Урожай — `generic_produce` с id сорта в NBT. Деревья, тростник и плоды на стволе — только у встроенных видов.
- **`BlockState`** = `stage`, `size` (4 ступени), `variant` (окраска), `ailing`, `village`, `active`. Рендер — запечённые модели по состоянию, без `BlockEntityRenderer` и `ModelData`. Логике (`isRandomlyTicking`, `isMaxAge`) доступ к BE не нужен.
- Архетип `field` наследует `CropBlock` (это нужно фермеру, ADR-0010).

## Альтернативы
1. **Только архетипные блоки + динамическая модель по виду через `ModelData`.** Один путь кода, но новый и рискованный рендер (`IDynamicBakedModel`, обновление `ModelData` при перестройке чанка); каждому блоку с видовой текстурой (листва, плоды) нужна BE; хуже совместимость с ресурспаками и Jade. Отклонено для MVP; остаётся возможным улучшением для датапачных видов.
2. **Только блоки на вид.** Не выполняет метрику 6.
3. **Размер и окраска в BE с синхронизацией.** Лишний сетевой трафик и `ModelData` без выигрыша.

## Последствия
- Плюсы: 95 % контента рендерится ванильным путём; клиенту не нужны данные BE; ресурспаки работают как обычно.
- Минусы: два пути (встроенный и архетипный); датапачные виды выглядят скромнее; число состояний (≈ 768 у моркови) увеличивает запекание моделей, но в допустимых пределах.
- Ограничение метрики 6 для датапачных видов записано в `05-architecture.md` §21.
