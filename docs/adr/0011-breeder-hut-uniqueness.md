# ADR-0011: Хижина селекционера — вариант стартового элемента деревни

## Статус
Предложено (2026-10-29). Требует согласия Level Designer (отклонение от `03-worldgen.md` §11.5).

## Контекст
GDD §9.6: не больше 1 хижины на деревню, примерно в 1 из 5 деревень, не в зомби-деревнях, с волны 2. В jigsaw 1.20.1 нельзя ограничить число элементов пула. Worldgen предложил свой тип элемента со счётчиком в `JigsawPlacement` — это mixin во внутренний класс.

## Решение
- Хижина — часть **нового стартового элемента** пулов `minecraft:village/<тип>/town_centers` (равнины, тайга, саванна, пустыня, снежная): «площадь с хижиной селекционера» — свой шаблон с колоколом, точкой сбора, соединителями улиц, хижиной и делянкой 3 × 5. У деревни ровно один стартовый элемент, поэтому «≤ 1» выполняется по построению.
- Частота задаётся весом точно: вес наших элементов = 25 % от суммы весов незомби-элементов пула → доля деревень с хижиной 20 %. Зомби-элементы не трогаем.
- Элемент добавляется в пул кодом на `ServerAboutToStartEvent` (AT на поля `StructureTemplatePool` `[ПРОВЕРИТЬ]` имена), только если загружена линия пшеницы. JSON пула не перекрываем.
- Шаблоны — наша работа, ванильные NBT не копируются.

## Альтернативы
1. **Свой тип элемента + mixin в `JigsawPlacement.Placer`** (пропуск, если хижина уже размещена). Хижина как обычный дом в любом месте, но mixin во внутренний приватный класс, конфликтующий с модами jigsaw. Запасной путь (M6), если LD отклонит решение.
2. **Низкий вес в пуле домов.** ≈ 2 % деревень с двумя хижинами — нарушает GDD. Отклонено (так же решил worldgen).
3. **Отдельная структура рядом с деревней.** Не «в деревне», сложно с размещением. Отклонено.

## Последствия
- Плюсы: без mixin, детерминированно, частота точная, ноль стоимости в рантайме.
- Минусы: хижина всегда у центра деревни; другие моды деревень, которые перекрывают пул стартовых элементов, могут её убрать (страховка — крафтовый сортировочный стол).
