## Решения владельца (2026-10-28) — подробно в `docs/00-vision.md`
- Радиус опыления — для каждого вида, по реальной биологии.
- Пчёлы опыляют культуры; ульи генерируются рядом с дикими патчами.
- Ванильных культур нет (по умолчанию `strict`); в деревнях — промежуточные сорта; в структурах — первородные семена.
- Поддержка Farmer's Delight: его культуры переделываются в линии селекции.
- JDK 17 скачивает Gradle toolchain автоматически (foojay resolver).
